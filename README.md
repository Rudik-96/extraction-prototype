# Extraction Prototype

Прототип мобильной 2D-игры в жанре extraction: зашёл на карту, собрал лут, выбрался живым.
Стек: Pixi.js v8, TypeScript, Vite. Сервер не нужен, все ресурсы локальные.

## Команды

Установка зависимостей:

```bash
npm install
```

| Команда               | Что делает                                         |
| --------------------- | -------------------------------------------------- |
| `npm run dev`         | Запуск для разработки на этом компьютере           |
| `npm run dev:lan`     | То же, но игру можно открыть с телефона            |
| `npm run typecheck`   | Проверка типов                                     |
| `npm run build`       | Проверка типов и сборка в `dist/`                  |
| `npm run preview`     | Запуск собранной версии                            |
| `npm run preview:lan` | Запуск собранной версии с доступом с телефона      |

## Как открыть на телефоне

1. Телефон и компьютер должны быть в одной Wi-Fi-сети.
2. Выполните `npm run dev:lan`.
3. Откройте на телефоне адрес из строки `Network:` в терминале, например `http://192.168.1.10:5173/`.

Если страница не открывается, проверьте, что файрвол компьютера разрешает входящие подключения для Node.js.
Сервер в этом режиме виден всем устройствам в сети, поэтому запускайте его только в доверенной сети.

## Управление

- **Телефон:** приложите палец в любом месте экрана и ведите его, как джойстик.
- **Компьютер:** WASD или стрелки. Мышь работает так же, как палец.

## Правила забега

Соберите лут и простойте 2 секунды в зелёной зоне выхода: стрелка у героя показывает, куда идти.
Если герой погибнет или закончатся 3 минуты, лут за этот забег пропадёт.
Самый ценный лут лежит в комнатах наверху под охраной.

## Улучшения

Лут тратится на экране улучшений: урон, скорость стрельбы, дальность, здоровье и скорость бега.
Прибавки и цены заданы в `BALANCE.upgrades`, уровни хранятся в сохранении.

## Структура

```
src/
  main.ts        точка входа
  config/        balance.ts (все числа баланса), display.ts (экран, цикл, джойстик)
  core/          Game, GameLoop, SceneManager, Viewport
  game/          логика: мир, сущности, карта, столкновения. Без Pixi
  input/         клавиатура и логика джойстика
  view/          отрисовка мира и камера. Только читает состояние из game/
  save/          прогресс игрока и его хранилище
  scenes/        меню, забег, результат, улучшения
  ui/            кнопки, подписи, вид джойстика
```

- **Цикл.** Логика считается шагами по 1/60 секунды в `fixedUpdate(dt)`, отрисовка — в `render(alpha)`.
- **Сущности.** Логика лежит в `game/`, а вид — в `view/`. Враги и снаряды берутся из пула `Pool`,
  и у каждого объекта пула постоянный вид (`PooledViews`). Для перехода на Spine достаточно заменить классы вида.
- **Поиск пути.** Обход сетки от героя (`FlowField`) считается один раз на всех врагов и только при смене клетки героя.
  Если герой виден вблизи, враг идёт прямо к нему.
- **Сохранения.** Игра работает с `Progress`, а запись идёт через интерфейс `ProgressStorage`. Он асинхронный,
  поэтому для перехода на Firebase достаточно написать новую реализацию вместо `LocalStorageProgressStorage`.
- **Экран.** Сцены верстаются в логических единицах: ширина всегда 390, высота зависит от устройства.
  На телефоне игра занимает весь экран. Если окно шире пропорции 9:16 (компьютер, планшет),
  по бокам появляются чёрные поля, поэтому на компьютере видно столько же, сколько на телефоне.
